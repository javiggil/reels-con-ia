# animar-reels

Skill de Claude Code que convierte un .wav de alguien hablando a cámara y su guion en los dos
entregables de un reel animado con HyperFrames: subtítulos 4K con alfa (sincronía por alineación
forzada CTC) y clips de animación estilo demo de app (opacos o alfa), más la tabla de montaje y la
reconciliación del guion. Funciona para cualquier creador y cualquier editor.

Empieza por `SKILL.md`, rellena `reference/brief-plantilla.md` una vez y lanza
`scripts/nuevo-reel.sh <nombre> <audio.wav>`.

Método de Javi Gil, @javiggil.
